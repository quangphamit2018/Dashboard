Cấu hình Token / Kết nối dữ liệu✕
Nút trên gọi 1 Supabase Edge Function (proxy) để lấy dữ liệu Jira mới nhất — cần bạn đã deploy function jira-sync theo hướng dẫn riêng. Việc đồng bộ toàn bộ ticket có thể mất khoảng 30–90 giây tuỳ số lượng. Token được lưu trong bảng, chỉ đọc/ghi được khi cung cấp đúng mật khẩu Admin (qua hàm RPC bảo mật) — không expose trực tiếp qua REST API. Nút "Kiểm tra kết nối Jira" gọi thẳng Jira API từ trình duyệt để xác thực Token còn hạn hay không; do chính sách CORS của Atlassian Cloud, request này có thể bị chặn (lỗi "Failed to fetch") dù Token đúng — không ảnh hưởng đến nút "Đồng bộ dữ liệu Jira" ở trên vì nút đó gọi qua Edge Function (server-side), không bị CORS chặn.
